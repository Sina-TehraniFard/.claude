# HTML スライド資料の生成（編集・並べ替え対応版）

説明・レクチャー・概要・提案などの内容を、**単一の HTML ファイル**としてスライド資料化する。ブラウザで開くだけでプレゼンのように 1 画面ずつ閲覧でき、さらに**サイドバー目次をドラッグ&ドロップで並べ替え**、その順序を**HTML ファイル自体に自動保存**できる。

## このスキルが備える機能（テンプレート由来）

1. **1画面 = 1スライド**：メイン領域に 1 枚ずつ表示。
2. **サイドバー目次**：全スライドのタイトルを並べ、クリック/キーで切り替え。現在のスライドをハイライト。
3. **キー操作で遷移**
   - `→` / `↓` / `PageDown` / `J`: 次のスライド
   - `←` / `↑` / `PageUp` / `K`: 前のスライド
   - `Home` / `End`: 先頭 / 末尾、`Space`: サイドバー開閉
   - 端ではループせず止まる。入力欄フォーカス中はキー操作を無効化。
4. **ドラッグ&ドロップ並べ替え**：目次の `⠿` ハンドルを掴んで順序変更（SortableJS はテンプレートにインライン埋め込み済み。CDN 不要でオフラインでも動作する）。
5. **ファイルへの順序自動保存**：File System Access API でこの HTML ファイル自体を上書き保存。並べ替えた状態のファイルを他者に渡せば、相手の画面でも順序が維持される（Chrome / Edge 対応。初回のみファイル接続の許可が必要）。
6. **サイドバー開閉**：右側面のタブ or `Space` で開閉。
7. **アクセシビリティ**：目次は Tab フォーカス可・フォーカスリング表示・Enter で選択。

## 実装テンプレート

実コードは別ファイルに保存してある。**必ずこのファイルを Read して骨子とする**：

```
~/.claude/skills/html-slides/templates/editable-slides.html
```

このテンプレートは、各スライドを `<li data-id data-title data-body>` で表現し、JS が選択中スライドを data 属性からメイン領域へ流し込む方式。`<section>` を並べる従来方式とは構造が異なる（並べ替えと順序保存を成立させるため）。

### プレースホルダ

テンプレート内の `{{...}}` を内容で置き換える：

| プレースホルダ | 意味 |
|---|---|
| `{{タイトル}}` | `<title>`（ブラウザタブ名） |
| `{{スライドNのタイトル}}` | サイドバー目次に出す短いラベル |
| `{{スライドNの見出し}}` | メイン領域の大見出し（`data-title`） |
| `{{スライドNの本文}}` | メイン領域の本文（`data-body`。改行は実際の改行文字でOK） |

## 生成時の進め方

1. **テンプレートを Read** する（`templates/editable-slides.html`）。
2. ユーザーの内容を、スライド単位の論理構成に分解する（表紙 → 全体像 → 各論 → まとめ）。詰め込まない（1スライド = 見出し1つ＋要点を絞る）。
3. テンプレートの `<ul class="toc">` 内の `<li>` を、スライド枚数ぶん用意する。各 `<li>` に:
   - `data-id` は重複しない英数字（`s1`, `s2`, ... でよい）
   - `data-title` / `data-body` に内容
   - 最初に表示する 1 枚だけ `class="active"`
   - `<span class="num">` の番号と `<span class="label">` のラベルを設定
4. メイン領域 `#slide` の初期表示は、`active` にしたスライドの内容に合わせる。
5. `{{タイトル}}` を設定する。
6. 単一 HTML ファイルとして出力する。**保存先のファイル名はユーザーに確認する**（プロジェクトの CLAUDE.md に命名ルールがあればそれに従う）。

## デザイン方針: 明るく・スッキリ・モダン

- テンプレートは**ライトテーマ**（淡いグレー背景＋白カード＋藍アクセント、枠線控えめ・やわらかい影）。
- 余白を広く、見出しは大きく、本文は十分なコントラストで。
- アクセントカラーは `:root` の `--accent` 1 色で統一。色を変える指定があればここを差し替える。
- フォントは OS 標準（追加 CDN なしで軽快）。指定があれば Google Fonts 等を `<head>` に足す。

## 図・グラフを足したいとき（任意）

各スライドの本文はプレーンテキストが基本だが、図解が要る場合は本文ではなくメイン領域にリッチな HTML を差し込む拡張も可能。必要なら CDN を足す:
- 図: Mermaid（`https://cdn.jsdelivr.net/npm/mermaid/dist/mermaid.min.js`）。`mermaid.initialize({ startOnLoad: true })`。スライド切替後に崩れる場合は表示時に `mermaid.run()` を呼ぶ。
- 数値グラフ: Chart.js。
- 概念・フロー・関係・比較は文章より図で示すと伝わりやすい。
- **注意（ユーザーへ案内すべき点）**: Mermaid / Chart.js は CDN 読み込みのため、オフライン環境やネットワーク制限下では図・グラフが表示されない（スライド本体と並べ替えはオフラインでも動作する）。

## ファイル自動保存についての注意（ユーザーへ案内すべき点）

- **対応ブラウザは Chrome / Edge**（Safari・Firefox は File System Access API 非対応。開くと上部に警告が出る）。
- 初回は「📁 このファイルに接続して自動保存」ボタンを 1 度押し、対象 HTML を選んで書き込みを許可する必要がある（ブラウザのセキュリティ上、省略不可）。
- 2 回目以降は同じブラウザなら自動再接続を試みる（権限が残っていればボタン不要）。
- 保存は「並べ替えた瞬間の DOM を丸ごと書き戻す」方式。受け取った人は未接続・サイドバー開・先頭スライドの状態から見られるよう、保存時に一時状態をリセットしてある。
